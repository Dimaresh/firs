# Ozon Promo Bot

Этот скрипт автоматизирует ротацию товаров в акциях на Ozon с помощью Ozon Seller API. Он удаляет из акции предыдущие 5 товаров и добавляет новые 5.

## Требования

* Python 3
* `requests` библиотека (`pip install requests`)

## Настройка

1. Установите зависимости:
   ```bash
   pip install requests
   ```

2. Установите переменные окружения с вашими доступами к Ozon API:
   * `OZON_CLIENT_ID` - ваш Client-ID
   * `OZON_API_KEY` - ваш Api-Key
   * `OZON_ACTION_ID` - ID акции, в которой нужно ротировать товары

   Пример (Linux/macOS):
   ```bash
   export OZON_CLIENT_ID="ваш_id"
   export OZON_API_KEY="ваш_ключ"
   export OZON_ACTION_ID="id_акции"
   ```

## Использование через cron (Автоматизация раз в неделю)

Чтобы скрипт запускался автоматически каждую неделю, добавьте его в cron.

1. Откройте редактор cron:
   ```bash
   crontab -e
   ```

2. Добавьте следующую строку (пример запуска каждое воскресенье в 00:00):
   ```bash
   0 0 * * 0 OZON_CLIENT_ID="id" OZON_API_KEY="key" OZON_ACTION_ID="id_акции" /usr/bin/python3 /путь/к/ozon_promo_bot.py >> /путь/к/ozon_promo.log 2>&1
   ```
   *(Укажите правильные пути к вашему Python и к файлу скрипта).*

## Как это работает
- Скрипт сохраняет ID добавленных товаров в файл `promo_state.json`.
- При следующем запуске он считывает эти ID, деактивирует их в акции.
- Затем он получает список доступных кандидатов, исключает только что удаленные, берет 5 новых товаров и добавляет их в акцию по `max_action_price`.
- Обновленный список из 5 новых ID сохраняется в `promo_state.json`.
