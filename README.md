# Ozon Promo Bot (Web Interface)

Этот проект автоматизирует ротацию товаров в акциях на Ozon с помощью Ozon Seller API. Включает в себя веб-интерфейс для настройки параметров и управления процессом.

## Требования

* Python 3
* `Flask`
* `APScheduler`
* `requests`

## Установка и запуск

1. Установите зависимости:
   ```bash
   pip install Flask APScheduler requests
   ```

2. Запустите веб-сервер:
   ```bash
   python3 app.py
   ```

3. Откройте в браузере: `http://127.0.0.1:5000/`

## Использование интерфейса

- Введите **Client-Id** и **Api-Key** от вашего Ozon Seller аккаунта.
- Вы можете нажать **"Загрузить акции"**, чтобы получить список доступных акций и выбрать нужную из выпадающего списка (подставится ID).
- Укажите **количество товаров**, которое нужно ротировать (например, 5).
- Нажмите **"Сохранить настройки"**.
- После сохранения, скрипт автоматически будет менять указанное количество товаров в выбранной акции **раз в неделю**.
- Если вы хотите поменять товары прямо сейчас, нажмите красную кнопку **"Поменять товары раньше срока"**. Это сбросит таймер, и следующая плановая ротация произойдет ровно через неделю после этого нажатия.

## Логика ротации
- Состояние (ID текущих добавленных товаров) хранится локально в файле `promo_state.json`.
- При ротации скрипт удаляет из акции старые товары (которые записаны в состоянии).
- Запрашивает новых кандидатов, исключает только что удаленные и добавляет новые с `action_price`, равной `max_action_price`.
